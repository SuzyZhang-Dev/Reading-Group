# 期次海报

档案页（`../index.html`）的画廊会按**期次 slug** 自动加载这里的海报：

```
./posters/<slug>.jpg
```

把每期海报按对应文件名放进本目录即可，无需改代码或 JSON。缺失时画廊会显示「海报待补」占位块。

当前期次对应文件名：

| 期次 | 书名 | 海报文件名 |
|---|---|---|
| Vol.01 | 《进烤箱的好日子》 | `2026-03-22-kaoxiang.jpg` |
| Vol.02 | 《每一句话语都坐着别的眼睛》 | `2026-06-28-bie-de-yanjing.jpg` |
| Vol.03 | 《我不相信神话》 | `2026-07-26-myth.jpg` |
| Vol.04 | 《伊加利亚的女儿们》 | `2026-08-26-egalias.jpg` |

说明：
- 建议用 **JPG**、竖版、比例接近 **A 系列 1414×2000（≈1:1.414）**，画廊会以 `object-fit: cover` 统一裁切填充，其它尺寸也能用。
- 如果某张海报是 PNG，可在 `episodes.json` 对应条目里加一行 `"poster": "<slug>.png"` 覆盖默认的 `.jpg` 约定。
